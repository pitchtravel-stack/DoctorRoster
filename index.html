หมายเหตุ
วันหยุด (คลิกที่วันที่เพื่อสลับวันหยุด/วันทำการ) ชื่อซ้ำในช่วงเวลาเดียวกัน

ชื่อที่ใช้ในตาราง (ชื่อเล่น/ชื่อต้น) เรียงตามลำดับที่ต้องการให้แสดงในตัวเลือก
ลำดับแถว = ลำดับคอลัมน์ในตารางและไฟล์ Word · กลุ่ม/กลุ่มย่อยที่ติดกันจะถูกรวมหัวตารางให้อัตโนมัติ · "คอลัมน์ CSV" ใช้ตอนนำเข้าไฟล์ Excel (เช่น T, U, … Z)
บรรทัดละ 1 วัน รูปแบบ MM-DD|ชื่อวัน = ทุกปี หรือ YYYY-MM-DD|ชื่อวัน (ปี ค.ศ.) = เฉพาะปีนั้น เช่น วันหยุดชดเชย/วันหยุดพิเศษ · ใช้ตอนสร้างเดือนใหม่ (เสาร์-อาทิตย์เป็นวันหยุดอัตโนมัติ)
admin = ทุกอย่าง · editor = จัด/แก้ตารางเวร · viewer = ดูและดาวน์โหลดเท่านั้น

การจัดตารางเวรเดือนใหม่

  1. เลือกเดือนที่ช่องด้านบน — ถ้ายังไม่มีข้อมูล ระบบสร้างตารางว่างพร้อมวันหยุด (เสาร์-อาทิตย์ + รายการวันหยุดในตั้งค่า)
  2. คลิกที่ตัวเลขวันที่เพื่อสลับวันหยุด/วันทำการ (เช่น วันหยุดพิเศษ)
  3. เลือกชื่อแพทย์ในแต่ละช่อง หรือกด นำเข้า CSV จาก Excel (บันทึกไฟล์ตารางเวรจาก Excel เป็น CSV UTF-8) ระบบอ่านคอลัมน์ A (วันที่) และคอลัมน์ตามที่ตั้งไว้ (T–Z)
  4. กด บันทึก แล้วกด ⬇ Word เพื่อได้ไฟล์ตารางเวรสำหรับลงนาม/ติดประกาศ
  5. หน้า สรุปค่าตอบแทน นับจำนวนเวรและคำนวณเงินรายคนตามอัตราในตั้งค่า (เลือกครึ่งเดือนได้)

หากเปลี่ยนอัตราค่าตอบแทน ให้แก้ที่ ตั้งค่า → ประเภทเวร/อัตรา (มีผลกับการคำนวณทุกเดือน)
